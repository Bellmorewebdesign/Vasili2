# Fonts

Self-hosted Latin subsets, downloaded from Google Fonts. All three families are licensed under the SIL Open Font License 1.1, which allows bundling with a website.

- `cormorant-garamond-latin.woff2`: Cormorant Garamond (variable weight), headings
- `hanken-grotesk-latin.woff2`: Hanken Grotesk (variable weight), text and navigation
- `ibm-plex-mono-400-latin.woff2`: IBM Plex Mono Regular, item numbers and small labels
